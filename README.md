Small alteration of [SliFractalAsm](https://github.com/cricri-pingouin/SliFractalAsm) in which iterations are increased by user changeable values of CR  and Ci instead of c1 and c2 for the Mandelbrot set.

This was just for completeness sake of offering asm routines, but will not be updated.

Please look at SliJulia for an improved version with more features. I still fixed a X <-> Y bug that was preventing correct rendering if canvas height and width differed, but any further updates will be for the new repository.

Bear in mind the new repository does not use asm and may never will, so if you are after a working asm routine for a Julia set, this is still the one to come to.
