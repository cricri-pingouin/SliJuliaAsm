Small alteration of [SliFractalAsm](https://github.com/cricri-pingouin/SliFractalAsm) in which iterations are increased by fixed (but user customisable) values of Cr and Ci instead of C1 and C2 to render a Julia set instead of a Mandelbrot set.

This is just for completeness sake of offering asm routines for both sets, but will not be updated.

Please look at SliJulia for an improved version with more features. Any further updates will be for the new repository.

Bear in mind the new repository does not use asm and may never will, so if you are after a working asm routine for a Julia set, this is still the one to come to.
